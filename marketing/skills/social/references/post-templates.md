# Templates de posts

Templates prêts à l'emploi pour différentes plateformes et types de contenu.

## Sommaire
- Templates LinkedIn (Post narratif, Prise de position, Post liste, Tutoriel)
- Templates Thread Twitter/X (Thread tutoriel, Thread narratif, Thread décryptage)
- Templates Instagram (Hook carrousel, Script Reel)
- Formules de hooks (Curiosité, Narratif, Valeur, Contre-courant, Preuve sociale)

> **Note sur le registre :** Les exemples ci-dessous utilisent le vouvoiement, courant en contexte pro et B2C français. Le tutoiement est fréquent et tout à fait légitime sur les réseaux (surtout TikTok, Instagram, communautés de niche) : adapte selon la marque et l'audience.

## Templates LinkedIn

### Le post narratif
```
[Hook : résultat inattendu ou leçon tirée]

[Mise en scène : quand / dans quel contexte]

[Le défi rencontré]

[Ce que tu as essayé / ce qui s'est passé]

[Le tournant]

[Le résultat]

[La leçon pour les lecteurs]

[Question pour susciter les commentaires]
```

### La prise de position
```
[Opinion impopulaire formulée sans détour]

Voici pourquoi :

[Raison 1]
[Raison 2]
[Raison 3]

[Ce que tu recommandes à la place]

[Invite au débat : « J'ai tort ? »]
```

### Le post liste
```
[X choses apprises sur [sujet] après [élément de crédibilité]] :

1. [Point] : [Brève explication]

2. [Point] : [Brève explication]

3. [Point] : [Brève explication]

[Insight de synthèse]

Laquelle vous parle le plus ?
```

### Le tutoriel
```
Comment [atteindre ce résultat] en [délai] :

Étape 1 : [Action]
↳ [Pourquoi c'est important]

Étape 2 : [Action]
↳ [Détail clé]

Étape 3 : [Action]
↳ [Erreur courante à éviter]

[Résultat attendu]

[CTA ou question]
```

## Templates Thread Twitter/X

### Le thread tutoriel
```
Tweet 1 : [Hook + promesse de valeur]

« Voici exactement comment [résultat] (étape par étape) : »

Tweets 2-7 : [Une étape par tweet avec détails]

Tweet final : [Récap + CTA]

« Si c'était utile, suivez-moi pour plus de contenu sur [sujet] »
```

### Le thread narratif
```
Tweet 1 : [Hook intrigant]

« Il y a [durée], [événement inattendu s'est produit]. Voici toute l'histoire : »

Tweets 2-6 : [Séquence narrative, montée en tension]

Tweet 7 : [Dénouement et leçon]

Tweet final : [Enseignement + invitation à l'engagement]
```

### Le thread décryptage
```
Tweet 1 : [Entreprise / personne] vient de [faire quelque chose].

Voici pourquoi c'est brillant (et ce qu'on peut en retenir) :

Tweets 2-6 : [Points d'analyse]

Tweet 7 : [Ton enseignement principal]

« [Insight connexe + invitation à suivre] »
```

## Templates Instagram

### Le hook carrousel
```
[Slide 1 : affirmation forte ou question percutante]
[Slides 2-9 : un point par slide, visuel + texte]
[Slide 10 : récap + CTA]

Légende : [Développe le sujet, apporte du contexte, CTA]
```

### Le script Reel
```
Hook (0-2 s) : [Rupture de pattern ou affirmation audacieuse]
Mise en contexte (2-5 s) : [Contexte du conseil]
Valeur (5-25 s) : [Le contenu réel / le conseil]
CTA (25-30 s) : [Suivre, commenter, partager, lien]
```

## Formules de hooks

La première ligne décide si quelqu'un lit la suite.

### Hooks de curiosité
- « J'avais tort sur [idée reçue]. »
- « La vraie raison pour laquelle [résultat] se produit n'est pas celle qu'on croit. »
- « [Résultat impressionnant], en seulement [durée surprenante]. »
- « Personne ne parle de [information d'initié]. »

### Hooks narratifs
- « La semaine dernière, [événement inattendu] s'est passé. »
- « J'ai failli [grosse erreur / échec]. »
- « Il y a 3 ans, je [situation passée]. Aujourd'hui, [situation actuelle]. »
- « [Quelqu'un] m'a dit quelque chose que je n'oublierai jamais. »

### Hooks de valeur
- « Comment [résultat souhaité] sans [obstacle courant] : »
- « [Nombre] [choses] qui [résultat] : »
- « La façon la plus simple de [résultat] : »
- « Arrête de [erreur courante]. Fais plutôt ça : »

### Hooks à contre-courant
- « Avis impopulaire : [affirmation audacieuse] »
- « [Conseil répandu] est faux. Voilà pourquoi : »
- « J'ai arrêté de [pratique courante] et [résultat positif]. »
- « Tout le monde dit [X]. La vérité, c'est [Y]. »

### Hooks de preuve sociale
- « Nous avons [atteint ce résultat] en [délai]. Voici toute l'histoire : »
- « [Nombre] personnes m'ont posé la même question sur [sujet]. Voici ma réponse : »
- « [Figure d'autorité] m'a appris [leçon]. »
