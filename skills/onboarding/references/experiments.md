# Idées d'expérimentations : onboarding

Liste exhaustive de tests A/B et d'expérimentations pour l'onboarding et l'activation utilisateur.

## Sommaire
- Simplification du flux (réduction de la friction, ordonnancement des étapes, progression et motivation)
- Expérience guidée (visites produit, optimisation des CTA, guidage UI)
- Personnalisation (segmentation, contenu dynamique)
- Victoires rapides et engagement (time-to-value, mécaniques de motivation, aide et support)
- E-mail et multi-canal (e-mails d'onboarding, contenu e-mail, boucles de feedback)
- Réactivation (récupération des utilisateurs bloqués, expérience de retour)
- Technique et UX (performance, onboarding mobile, accessibilité)
- Métriques à suivre

## Simplification du flux

### Réduction de la friction

| Test | Hypothèse |
|------|-----------|
| Timing de la vérification e-mail | Pendant vs. après l'onboarding |
| Empty states vs. données fictives | Exemples pré-remplis |
| Templates pré-remplis | Accélérer le setup avec des modèles |
| Options OAuth | Connexion de compte plus rapide |
| Nombre d'étapes obligatoires | Moins d'étapes requises |
| Champs obligatoires vs. optionnels | Réduire les exigences |
| Options de passage | Permettre d'ignorer les étapes non critiques |

### Ordonnancement des étapes

| Test | Hypothèse |
|------|-----------|
| Ordre des étapes | Tester différentes séquences |
| Valeur d'abord | Les fonctionnalités les plus utiles en premier |
| Placement de la friction | Reporter les étapes difficiles |
| Ratio obligatoire/optionnel | Proportion d'étapes requises |
| Chemin unique vs. branches | Un seul parcours vs. parcours personnalisé |
| Démarrage rapide vs. setup complet | Chemin minimal vers la valeur |

### Progression et motivation

| Test | Hypothèse |
|------|-----------|
| Barres de progression | Afficher le pourcentage de complétion |
| Longueur de la checklist | 3-5 éléments vs. 5-7 éléments |
| Gamification | Badges, récompenses, accomplissements |
| Affichage de la complétion | Visibilité du « X % complété » |
| Point de départ | Commencer à 20 % vs. 0 % |
| Moments de célébration | Valoriser les complétions |

## Expérience guidée

### Visites produit

| Test | Hypothèse |
|------|-----------|
| Visites interactives | Outils comme Navattic, Storylane |
| Infobulle vs. modale | Discret vs. accrocheur |
| Tutoriels vidéo | Pour les workflows complexes |
| Rythme libre vs. guidé | Contrôle utilisateur vs. structure imposée |
| Longueur de la visite | Plus courte vs. plus complète |
| Déclenchement de la visite | Automatique vs. à l'initiative de l'utilisateur |

### Optimisation des CTA

| Test | Hypothèse |
|------|-----------|
| Variantes de texte des CTA | Tester des formulations orientées action |
| Placement des CTA | Position dans les écrans |
| Infobulles in-app | Prompts de découverte de fonctionnalités |
| CTA persistants | Rester visibles pendant l'onboarding |
| Contraste des CTA | Visibilité visuelle |
| CTA secondaires | « En savoir plus » vs. action principale uniquement |

### Guidage UI

| Test | Hypothèse |
|------|-----------|
| Hotspots | Attirer l'attention sur les fonctionnalités clés |
| Coachmarks | Conseils contextuels |
| Annonces de fonctionnalités | Découverte des nouveautés |
| Aide contextuelle | Aide là où l'utilisateur en a besoin |
| Recherche vs. guidage | Self-service vs. direction imposée |

## Personnalisation

### Segmentation

| Test | Hypothèse |
|------|-----------|
| Onboarding par rôle | Parcours différents selon le rôle |
| Parcours par objectif | Personnaliser selon l'objectif déclaré |
| Tableaux de bord par rôle | Vues par défaut pertinentes |
| Question d'usage | Personnaliser selon la réponse |
| Parcours par secteur | Personnalisation verticale |
| Parcours selon l'expérience | Débutant vs. expert |

### Contenu dynamique

| Test | Hypothèse |
|------|-----------|
| Message de bienvenue personnalisé | Prénom, entreprise, rôle |
| Exemples par secteur | Cas d'usage pertinents |
| Recommandations dynamiques | Basées sur les réponses de l'utilisateur |
| Suggestions de templates | Pré-remplis pour le segment |
| Mise en avant de fonctionnalités | Alignée sur les objectifs déclarés |
| Données de référence | Métriques propres au secteur |

## Victoires rapides et engagement

### Time-to-value

| Test | Hypothèse |
|------|-----------|
| Première victoire rapide | « Réalisez votre premier X » |
| Messages de succès | Après les actions clés |
| Célébrations de progression | Moments de milestone |
| Suggestions d'étape suivante | Après chaque complétion |
| Démonstration de valeur | Montrer ce que l'utilisateur a accompli |
| Aperçu du résultat | À quoi ressemble le succès |

### Mécaniques de motivation

| Test | Hypothèse |
|------|-----------|
| Badges d'accomplissement | Éléments de gamification |
| Séries consécutives | Engagement jour après jour |
| Classements | Comparaison sociale (si pertinente) |
| Récompenses | Incitations à la complétion |
| Mécanique de déblocage | Fonctionnalités dévoilées progressivement |

### Aide et support

| Test | Hypothèse |
|------|-----------|
| Appels d'onboarding offerts | Pour les produits complexes |
| Aide contextuelle | Tout au long de l'onboarding |
| Support par chat | Disponibilité pendant l'onboarding |
| Prise de contact proactive | Pour les utilisateurs bloqués |
| Ressources en self-service | Documentation, vidéos |
| Accès à la communauté | Entraide entre pairs dès le début |

## E-mail et multi-canal

### E-mails d'onboarding

| Test | Hypothèse |
|------|-----------|
| E-mail de bienvenue du fondateur | Personnalisé vs. générique |
| Déclencheurs comportementaux | Basés sur les actions/inactions |
| Timing d'envoi | Immédiat vs. différé |
| Fréquence d'envoi | Plus vs. moins de points de contact |
| Format « tips rapides » | Contenu court et actionnable |
| Vidéo dans l'e-mail | Format plus engageant |

### Contenu des e-mails

| Test | Hypothèse |
|------|-----------|
| Objets | Optimisation du taux d'ouverture |
| Niveau de personnalisation | Prénom vs. basé sur le comportement |
| Mise en avant du CTA | Une seule action claire |
| Inclusion de preuves sociales | Témoignages dans l'e-mail |
| Messages d'urgence | Rappels de fin d'essai |
| Texte brut vs. designé | Test de format |

### Boucles de feedback

| Test | Hypothèse |
|------|-----------|
| NPS pendant l'onboarding | Quand le demander |
| Question bloquante | « Qu'est-ce qui vous retient ? » |
| Suites au NPS | Actions selon le score |
| Feedback in-app | Pouce haut/bas sur les fonctionnalités |
| Timing du questionnaire | Quand solliciter un retour |
| Incentives au feedback | Récompenser la participation |

## Réactivation

### Récupération des utilisateurs bloqués

| Test | Hypothèse |
|------|-----------|
| Timing de l'e-mail de réactivation | Quand l'envoyer |
| Prise de contact humaine | Humain vs. automatisé |
| Parcours simplifié | Moins d'étapes pour les utilisateurs qui reviennent |
| Offre incitative | Réduction ou extension d'essai |
| Identification du blocage | Demander ce qui coince |
| Offre de démo | Visite guidée en direct |

### Expérience de retour

| Test | Hypothèse |
|------|-----------|
| Message de retrouvaille | Valoriser le retour |
| Reprise de la progression | Reprendre où l'utilisateur en était |
| État modifié | Ce qui s'est passé pendant l'absence |
| Re-onboarding | Option de recommencer à zéro |
| Messages d'urgence | Temps restant sur l'essai |

## Technique et UX

### Performance

| Test | Hypothèse |
|------|-----------|
| Optimisation du temps de chargement | Plus rapide = meilleure complétion |
| Chargement progressif | Performance perçue |
| Fonctionnement hors-ligne | Expérience mobile |
| Gestion des erreurs | Récupération gracieuse des échecs |

### Onboarding mobile

| Test | Hypothèse |
|------|-----------|
| Zones de toucher | Taille et espacement |
| Navigation par glissement | Patterns natifs mobiles |
| Nombre d'écrans | Moins d'écrans nécessaires |
| Formulaires adaptés | Formulaires optimisés pour mobile |
| Timing des permissions | Quand les demander |

### Accessibilité

| Test | Hypothèse |
|------|-----------|
| Compatibilité lecteur d'écran | Impact de l'accessibilité |
| Navigation clavier | Utilisateurs sans souris |
| Contraste des couleurs | Lisibilité |
| Taille des polices | Confort de lecture |

## Métriques à suivre

Pour toutes les expérimentations, mesurer :

| Métrique | Description |
|----------|-------------|
| Taux d'activation | % atteignant l'événement d'activation |
| Délai jusqu'à l'activation | Heures/jours jusqu'à la première valeur |
| Taux de complétion par étape | % complétant chaque étape |
| Points de décrochage | Où les utilisateurs abandonnent |
| Taux de retour | Utilisateurs qui reviennent |
| Rétention J1/J7/J30 | Engagement dans le temps |
| Adoption des fonctionnalités | Quelles fonctionnalités sont utilisées |
| Demandes de support | Volume pendant l'onboarding |
