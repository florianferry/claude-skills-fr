# Checklists de configuration des plateformes

Checklists de configuration complètes pour les principales plateformes publicitaires.

## Sommaire
- Configuration Google Ads (fondations du compte, tracking de conversion, intégration analytics, audiences, campagnes, extensions, protection de marque)
- Configuration Meta Ads (fondations Business Manager, pixel et tracking, domaine et événements agrégés, audiences, catalogue, créatifs, conformité)
- Configuration LinkedIn Ads (fondations Campaign Manager, Insight Tag et tracking, audiences, formulaires de génération de leads, Document Ads, créatifs, considérations budgétaires)
- Configuration Twitter/X Ads (fondations du compte, tracking, audiences, créatifs)
- Configuration TikTok Ads (fondations du compte, pixel et tracking, audiences, créatifs)
- Checklist pré-lancement universelle

## Configuration Google Ads

### Fondations du compte

- [ ] Compte Google Ads créé et vérifié
- [ ] Informations de facturation ajoutées
- [ ] Fuseau horaire et devise correctement configurés
- [ ] Accès accordé aux membres de l'équipe

### Tracking de conversion

- [ ] Google tag installé sur toutes les pages
- [ ] Actions de conversion créées (achat, lead, inscription)
- [ ] Valeurs de conversion attribuées (si applicable)
- [ ] Enhanced Conversions activées
- [ ] Conversions de test déclenchées correctement
- [ ] Import de conversions depuis GA4 (optionnel)

### Intégration analytics

- [ ] Google Analytics 4 lié
- [ ] Balisage automatique activé
- [ ] Audiences GA4 disponibles dans Google Ads
- [ ] Tracking inter-domaines configuré (si plusieurs domaines)

### Configuration des audiences

- [ ] Tag de remarketing vérifié
- [ ] Audiences de visiteurs du site créées :
  - Tous les visiteurs (180 jours)
  - Visiteurs des pages clés (tarifs, démo, fonctionnalités)
  - Convertis (pour exclusion)
- [ ] Listes de customer match importées
- [ ] Audiences similaires activées

### Prêt au lancement des campagnes

- [ ] Listes de mots-clés négatifs créées :
  - Négatifs universels (gratuit emploi recrutement avis plaintes)
  - Négatifs concurrents (si besoin)
  - Termes sectoriels non pertinents
- [ ] Ciblage géographique défini (zones incluses/exclues)
- [ ] Ciblage linguistique configuré
- [ ] Planification des annonces configurée (si B2B, heures ouvrables)
- [ ] Ajustements d'enchères par appareil examinés

### Extensions d'annonce

- [ ] Sitelinks (4 à 6 pages pertinentes)
- [ ] Accroches (bénéfices clés, offres)
- [ ] Extraits de site structurés (fonctionnalités, types, services)
- [ ] Extension d'appel (si les leads téléphoniques sont utiles)
- [ ] Extension de formulaire de lead (si applicable)
- [ ] Extensions de prix (si applicable)
- [ ] Extensions d'image (là où disponibles)

### Protection de marque

- [ ] Campagne sur les termes de marque en place (protéger les termes brandés)
- [ ] Campagnes concurrentes envisagées
- [ ] Termes de marque en mots-clés négatifs des campagnes hors marque

## Configuration Meta Ads

### Fondations Business Manager

- [ ] Business Manager créé
- [ ] Entreprise vérifiée (si certains formats publicitaires l'exigent)
- [ ] Compte publicitaire créé dans Business Manager
- [ ] Moyen de paiement ajouté
- [ ] Accès équipe configuré avec les bons rôles

### Pixel et tracking

- [ ] Meta Pixel installé sur toutes les pages
- [ ] Événements standard configurés :
  - PageView (automatique)
  - ViewContent (pages produit/fonctionnalité)
  - Lead (soumissions de formulaire)
  - Purchase (conversions)
  - AddToCart (si e-commerce)
  - InitiateCheckout (si e-commerce)
- [ ] Conversions API (CAPI) configurée pour le tracking côté serveur
- [ ] Score de qualité de correspondance des événements > 6
- [ ] Événements de test dans Events Manager

### Domaine et événements agrégés

- [ ] Domaine vérifié dans Business Manager
- [ ] Aggregated Event Measurement configuré
- [ ] 8 événements clés priorisés par ordre d'importance business
- [ ] Événements web priorisés pour le tracking iOS 14+

### Configuration des audiences

- [ ] Audiences personnalisées créées :
  - Visiteurs du site (tous, 30/60/90/180 jours)
  - Visiteurs des pages clés
  - Spectateurs vidéo (25 %, 50 %, 75 %, 95 %)
  - Personnes ayant interagi avec la page/Instagram
  - Liste clients importée
- [ ] Audiences similaires créées (1 %, 1 à 3 %)
- [ ] Audiences enregistrées pour les ciblages récurrents

### Catalogue (e-commerce)

- [ ] Catalogue produits connecté
- [ ] Flux produits mis à jour correctement
- [ ] Campagnes ventes via catalogue activées
- [ ] Dynamic Product Ads configurées

### Assets créatifs

- [ ] Images aux formats corrects :
  - Fil : 1 080 x 1 080 (1:1)
  - Stories/Reels : 1 080 x 1 920 (9:16)
  - Paysage : 1 200 x 628 (1,91:1)
- [ ] Vidéos aux formats corrects
- [ ] Variations de copy publicitaire prêtes
- [ ] Paramètres UTM dans toutes les URL de destination

### Conformité

- [ ] Catégories d'annonces spéciales déclarées (si logement, crédit, emploi, politique)
- [ ] Page de destination conforme aux politiques Meta
- [ ] Aucun contenu interdit dans les annonces

## Configuration LinkedIn Ads

### Fondations Campaign Manager

- [ ] Compte Campaign Manager créé
- [ ] Page Entreprise connectée
- [ ] Informations de facturation ajoutées
- [ ] Accès équipe configuré

### Insight Tag et tracking

- [ ] LinkedIn Insight Tag installé sur toutes les pages
- [ ] Tag vérifié et actif
- [ ] Tracking des conversions configuré :
  - Conversions basées sur l'URL
  - Conversions basées sur des événements spécifiques
- [ ] Valeurs de conversion définies (si applicable)

### Configuration des audiences

- [ ] Matched Audiences créées :
  - Audiences de remarketing visiteurs du site
  - Liste d'entreprises importée (pour ABM)
  - Liste de contacts importée
- [ ] Audiences similaires créées
- [ ] Audiences enregistrées pour les ciblages récurrents

### Formulaires de génération de leads (si applicable)

- [ ] Modèles de formulaires créés
- [ ] Champs du formulaire sélectionnés (minimiser pour favoriser la conversion)
- [ ] URL de politique de confidentialité ajoutée
- [ ] Message de remerciement configuré
- [ ] Intégration CRM configurée (ou processus d'export CSV)

### Document Ads (si applicable)

- [ ] Documents importés (PDF, PowerPoint)
- [ ] Accès configuré (accès complet ou aperçu)
- [ ] Formulaire de génération de leads connecté

### Assets créatifs

- [ ] Images single : 1 200 x 627 (1,91:1) ou 1 080 x 1 080 (1:1)
- [ ] Images carousel prêtes
- [ ] Spécifications vidéo respectées (si applicable)
- [ ] Copy dans les limites de caractères :
  - Texte d'intro : 600 max, 150 recommandés
  - Titre : 200 max, 70 recommandés

### Considérations budgétaires

- [ ] Budget réaliste au regard des CPC LinkedIn (8 à 15 € typiquement)
- [ ] Taille d'audience validée (50 000+ recommandé)
- [ ] Budget journalier vs. budget à vie décidé
- [ ] Stratégie d'enchères sélectionnée

## Configuration Twitter/X Ads

### Fondations du compte

- [ ] Compte publicitaire créé
- [ ] Moyen de paiement ajouté
- [ ] Compte vérifié (si requis)

### Tracking

- [ ] Twitter Pixel installé
- [ ] Événements de conversion créés
- [ ] Tag site web vérifié

### Configuration des audiences

- [ ] Audiences personnalisées créées :
  - Visiteurs du site
  - Listes clients
- [ ] Audiences similaires aux abonnés identifiées
- [ ] Centres d'intérêt et ciblages par mots-clés recherchés

### Créatifs

- [ ] Copy tweet dans la limite des 280 caractères
- [ ] Images : 1 200 x 675 (1,91:1) ou 1 200 x 1 200 (1:1)
- [ ] Spécifications vidéo respectées (si applicable)
- [ ] Cards configurées (site web, app, etc.)

## Configuration TikTok Ads

### Fondations du compte

- [ ] Compte TikTok Ads Manager créé
- [ ] Vérification entreprise complétée
- [ ] Moyen de paiement ajouté

### Pixel et tracking

- [ ] TikTok Pixel installé
- [ ] Événements configurés (ViewContent, Purchase, etc.)
- [ ] Events API configurée (recommandé)

### Configuration des audiences

- [ ] Audiences personnalisées créées
- [ ] Audiences similaires créées
- [ ] Catégories d'intérêt identifiées

### Créatifs

- [ ] Vidéo verticale (9:16) prête
- [ ] Contenu à rendu natif (pas trop léché)
- [ ] Les 3 premières secondes constituent une accroche forte
- [ ] Sous-titres ajoutés (la plupart regardent sans le son)
- [ ] Musique/sons sélectionnés (avec droits si nécessaire)

## Checklist pré-lancement universelle

Avant de lancer toute campagne :

- [ ] Tracking de conversion testé avec une vraie conversion
- [ ] Page de destination rapide (moins de 3 s)
- [ ] Page de destination adaptée au mobile
- [ ] Paramètres UTM fonctionnels
- [ ] Budget configuré correctement (journalier vs. à vie)
- [ ] Dates de début et de fin correctes
- [ ] Ciblage conforme à l'audience visée
- [ ] Créatifs publicitaires approuvés
- [ ] Équipe informée du lancement
- [ ] Tableau de bord de reporting prêt
